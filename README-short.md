# МОСЭВАК 24 — лендинг службы эвакуации

Сборка не нужна: чистые HTML/CSS/JS, размещается на GitHub Pages.

## Какая задача решается

Клиент считает цену в калькуляторе и оставляет заявку на сайте, не дожидаясь
ответа диспетчера по телефону. Заявки собираются в Google Таблицу — учёт ведётся
без отдельной CRM, и служба не теряет тех, кто не дозвонился.

## Для кого

Служба эвакуации (заказчик) и водители, которым срочно нужен эвакуатор — после
ДТП, при поломке или для перевозки автомобиля. Большинство клиентов открывают
сайт с телефона, поэтому мобильная версия и быстрый расчёт цены в приоритете.

## Основные функции и стек

- Калькулятор стоимости, форма заявки, интерактивная карта, каталог услуг.
- Frontend: HTML5, CSS3 (Grid/Flexbox), JavaScript ES2018+ — без фреймворков
  и сборки. Строгий CSP, доступность, SEO, адаптив.
- Внешние сервисы: Яндекс.Карты, Nominatim (OpenStreetMap), опционально
  Яндекс.Метрика и Google Apps Script для приёма заявок.
- Хостинг: GitHub Pages, статический сайт без бэкенда.

## Как запустить

```bash
python -m http.server 8000
```

Откройте http://localhost:8000/ (или через Node: `npx --yes serve -l 8000 .`).
